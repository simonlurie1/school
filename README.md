# משבצת

תרגול מתמטיקה ואנגלית לכיתות א'–ו' לפי תוכנית הלימודים. אתר סטטי (HTML + JavaScript), בלי שלב build.

- `index.html` – הממשק: בחירת כיתה, נושאים, שאלות, סיכום והקראה קולית.
- `math.js` – מנוע השאלות במתמטיקה לכל הכיתות (`window.MATH`).
- `english.js` – מנוע השאלות באנגלית (`window.ENGLISH`): בכיתות א'–ב' מקשיבים ובוחרים תמונה; מכיתה ג' אותיות, אוצר מילים ודקדוק. כפתור 🔊 קורא את האנגלית בקול אנגלי.
- `manifest.webmanifest`, `icons/` – הגדרות האפליקציה והאייקונים (התקנה למסך הבית).
- `sw.js` – service worker: האתר עובד גם בלי אינטרנט. כשמוסיפים קובץ לאתר, מוסיפים אותו לרשימה `APP_FILES` ומעלים את `VERSION`.

## בדיקת השאלות

```bash
node tests/verify.js
```

מייצר 2,000 שאלות מכל נושא בכל כיתה ובודק שהתשובות נכונות (מחשב כל תשובה מחדש בדרך עצמאית; בשאלות עם ציור, כמו ספירת עיגולים, מלבן במשבצות או סוג מרובע, הבדיקה נעשית מול הציור עצמו), שהתשובה מופיעה בין האפשרויות, ושאין בטקסט "undefined" או "NaN". באנגלית הבודק כותב מחדש את כללי הדקדוק (רבים, זמן עבר, השוואה ועוד) ובודק גם שאין ברשימת המילים שתי מילים עם אותה תמונה או אותו תרגום. להריץ אחרי כל שינוי ב־`math.js` או ב־`english.js`. אפשר לתת מספר אחר: `node tests/verify.js 10000`.

## התקנה כאפליקציה

- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **מחשב (Chrome/Edge):** אייקון ההתקנה בשורת הכתובת.

## הרצה מקומית

```bash
python -m http.server 8000
```

ואז לפתוח http://localhost:8000
