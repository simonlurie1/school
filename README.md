# משבצת

תרגול מתמטיקה, עברית ואנגלית לכיתות א'–ו' לפי תוכנית הלימודים. אתר סטטי (HTML + JavaScript), בלי שלב build.

- `index.html` – הממשק: בחירת כיתה, נושאים, שאלות, סיכום והקראה קולית.
- `math.js` – מנוע השאלות במתמטיקה לכל הכיתות (`window.MATH`).
- `hebrew.js` – מנוע השאלות בעברית/לשון (`window.HEBREW`): אותיות ואותיות סופיות, סדר מילון, זכר ונקבה, יחיד ורבים, זמנים, גופים, סימני פיסוק, נרדפות והפכים, כתיב (ת/ט, כ/ק/ח, א/ע, ס/ש), חלקי דיבר, נושא ונשוא, שורש, סמיכות, מילות יחס, בניינים, מילות קישור, ניבים וביטויים, הבנת הנקרא.
- `english.js` – מנוע השאלות באנגלית (`window.ENGLISH`): בכיתות א'–ב' מקשיבים ובוחרים תמונה; מכיתה ג' אותיות, אוצר מילים, דקדוק (there is/are, can, in/on/under, my/his/her, this/that, have got ועוד), חרוזים והבנת הנקרא. כפתור 🔊 קורא את האנגלית בקול אנגלי.
- `api/tts.js` – הקראה בקול איכותי של Google (פונקציה בשרת של Vercel). המפתח נשמר רק בשרת. בלי מפתח, או בלי אינטרנט, הדף משתמש בקול של הדפדפן. השרת עונה רק לדפי האתר ורק לטקסט שנראה כמו שאלה (אותיות, ספרות וסימנים מוכרים, עד 200 תווים); שאלה חדשה עם סימן חדש — מוסיפים אותו ל־`ALLOWED_TEXT` (הבודק מתריע על זה).
- `manifest.webmanifest`, `icons/` – הגדרות האפליקציה והאייקונים (התקנה למסך הבית).
- `sw.js` – service worker: האתר עובד גם בלי אינטרנט. כשמוסיפים קובץ לאתר, מוסיפים אותו לרשימה `APP_FILES` ומעלים את `VERSION`.

## בדיקת השאלות

```bash
node tests/verify.js
```

מייצר 2,000 שאלות מכל נושא בכל כיתה ובודק שהתשובות נכונות (מחשב כל תשובה מחדש בדרך עצמאית; בשאלות עם ציור, כמו ספירת עיגולים, מלבן במשבצות או סוג מרובע, הבדיקה נעשית מול הציור עצמו), שהתשובה מופיעה בין האפשרויות, ושאין בטקסט "undefined" או "NaN". בחשבון הוא בודק גם שהשאלה מתאימה לכיתה לפי תוכנית הלימודים של משרד החינוך: תחום המספרים (100 בכיתה א', 1,000 בכיתה ב', 10,000 בכיתה ג'), שברים יסודיים בלבד בכיתה ג', חילוק בתחום המאה עד כיתה ג', שטח בסמ״ר רק מכיתה ד', מיון מרובעים רק מכיתה ה', ראשוניים רק מכיתה ד', ואחוזים רק מכיתה ה'. בעברית ובאנגלית הוא בודק שכל נושא מופיע רק מהכיתה שבה הוא נלמד לפי תוכנית "חינוך לשוני" ו־English Curriculum 2020 (למשל בניינים וסמיכות מכיתה ה', השוואת תארים באנגלית בכיתה ו', ובאנגלית בכיתות א'-ב' רק האזנה). בעברית ובאנגלית הבודק כותב מחדש את כללי הדקדוק (רבים, זמן עבר, השוואה ועוד) ובודק גם שאין ברשימת המילים שתי מילים עם אותה תמונה או אותו תרגום. להריץ אחרי כל שינוי ב־`math.js`, `hebrew.js` או `english.js`. אפשר לתת מספר אחר: `node tests/verify.js 10000`.

## בדיקה שהתוכן מתאים לכיתה (סוכן)

הבודק האוטומטי מכיר רק כללים שנכתבו מראש. כדי לבדוק את כל התוכן מול תוכנית הלימודים יש סוכן בשם `curriculum-checker` (בקובץ `.claude/agents/curriculum-checker.md`).
- **איך מפעילים:** ב־Claude Code, בתיקיית הפרויקט, כותבים למשל: "תפעיל את curriculum-checker על חשבון כיתה ג'", או "תבדוק עם curriculum-checker את כל התוכן".
- **מה הוא עושה:**
  - קורא את תקציר תוכנית הלימודים ב־[`docs/curriculum.md`](docs/curriculum.md), ואם צריך גם את מסמכי משרד החינוך המקוריים.
  - מריץ את הבודק.
  - עובר על דוגמאות מכל נושא (`node tests/sample.js`).
- **מה מקבלים:** דוח בעברית עם השאלות שלא מתאימות לכיתה, מה כתוב בתוכנית, הצעה לתיקון, ותבניות בדיקה חדשות שאפשר להוסיף לבודק.
- הסוכן לא משנה קבצים, הוא רק מדווח.

כשמשרד החינוך מעדכן את התוכנית, מעדכנים את `docs/curriculum.md`.

## התקנה כאפליקציה

- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **מחשב (Chrome/Edge):** אייקון ההתקנה בשורת הכתובת.

```bash
python -m http.server 8000
```

## פרסום

קול איכותי להקראה: ב־Vercel ← Settings ← Environment Variables מוסיפים `GOOGLE_TTS_API_KEY` (מפתח של Google Cloud עם Text-to-Speech API), ומפרסמים מחדש. לא לשים את המפתח בקוד: האתר ציבורי.

ב־Vercel: לייבא את הריפו, Framework Preset = Other, בלי build command. כל push ל־`main` מתפרסם אוטומטית.
